DRIFT — an original vector-graphics asteroid shooter, stored as contract code on
Robinhood Chain and read back, verified, and run by chainrom. The fourth game and
a third kind of renderer: DEPTH raycasts, SIEGE draws sprites, DRIFT draws only
glowing lines with phosphor persistence. Every pixel is arithmetic — no image,
sound, or level files. Controls: arrows fly, space fires, shift jumps to
hyperspace. Clear the field to advance a wave.
